# Build

## Requirements

- Windows 10/11 x64 host.
- CMake 3.20+.
- Visual Studio 2022 or 2026 with the x86 (Win32) C++ toolchain and Windows SDK.
- Python 3 (used only to generate the installer payload arrays).
- The game installed locally for runtime testing.

The game is 32-bit. Build the DLL, launcher, injector and installer as **Win32**.

## Configure and build

From the project root:

```powershell
cmake -S . -B build -G "Visual Studio 18 2026" -A Win32
cmake --build build --config Release --parallel
```

For Visual Studio 2022 use `-G "Visual Studio 17 2022" -A Win32`.

## Outputs

`build/Release`:

| File | Purpose |
|---|---|
| `InvertoryHUD.dll` | the actual mod |
| `S2_HUD.exe` | starts `s2dng_addon.exe` and injects the DLL |
| `Injector.exe` | manual injector for development |
| `Probe.exe` | read-only diagnostics |
| `InvertoryHUD_Setup.exe` | self-contained installer |

The CMake build also copies the installer to `dist/InvertoryHUD_Setup.exe` and
the other executables to the game `bin` if `-DGAME_BIN_DIR=...` was supplied.

## Install into the game

Copy to `<game>\bin`:

- `InvertoryHUD.dll`
- `S2_HUD.exe`
- `InvertoryHUD.ini` (optional; the DLL writes defaults if missing)

or run `InvertoryHUD_Setup.exe` and select the game folder.

## Runtime files

The DLL writes next to itself:

- `InvertoryHUD.log` — diagnostics (overwritten each launch)
- `InvertoryHUD_crash.log` — vectored exception log
- `InvertoryHUD.ini` — settings

## Manual test

1. Launch `S2_HUD.exe` or launch `s2dng_addon.exe` and run `Injector.exe`.
2. Load a match.
3. The panel appears top-center when a local player is active.
4. `Probe.exe` prints the current device/player/map.

## Notes

- The DLL is compiled with the static MSVC runtime (`/MT`), so the target
  machine does not need a separate Visual C++ redistributable.
- The icon is embedded via `assets/S2_HUD.ico`.
- The installer payload is generated by `tools/embed_payload.py`; rebuild the
  installer after changing the DLL or launcher.
